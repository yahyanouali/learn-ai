Answer

Les règles encadrent le comportement invariant du modèle à chaque requête : elles sont résolues selon une hiérarchie stricte et injectées dans le message système.

  1. OpenCode découvre en priorité ~/.config/opencode/AGENTS.md puis le fichier ./AGENTS.md du dépôt.
  2. Cursor gère les règles via les fichiers .cursor/rules/*.mdc enrichis de métadonnées YAML et de motifs globaux.
  3. Chaque règle statique pèse sur le temps de Prefill et le coût mémoire du KV Cache à chaque tour.
  4. Les consignes temporaires ou dépendantes d'un contexte spécifique doivent être déléguées à des compétences ou des commandes.

Comment le runtime découvre-t-il les fichiers de règles ?

L'agent fusionne les directives globales de la machine avec les consignes locales du projet.
