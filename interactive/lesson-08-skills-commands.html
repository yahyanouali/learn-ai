Le motif de Progressive Disclosure préserve la fenêtre de contexte. L'agent ne charge que les métadonnées légères des compétences, puis lit le fichier SKILL.md complet uniquement à la demande.

  1. Les compétences sont déclarées dans un dossier avec un fichier SKILL.md doté d'un en-tête YAML.
  2. Au démarrage, seules les lignes de résumé (~100 jetons) sont incluses dans le prompt système de l'agent.
  3. Les commandes personnalisées permettent à l'utilisateur de déclencher des flux répétitifs via /nom_commande.
  4. Les variables dynamiques OpenCode ($ARGUMENTS, !shell, @fichier) injectent du contexte frais avant l'appel.

L'agent découvre dynamiquement les consignes approfondies sans encombrer le contexte initial.

  1. 1. Enregistrement Léger ↗

    Au lancement, seules les balises de nom et de description sont lues pour économiser le contexte.

  2. 2. Détection du Besoin ↗

    Le modèle repère un mot-clé ou un objectif nécessitant un outillage ou un format spécifique.

  3. 3. Lecture du Fichier Complet ↗

    L'agent appelle son outil de lecture pour charger l'intégralité du document SKILL.md.

  4. 4. Application Déterministe ↗

    L'agent exécute les scripts ou suit les directives spécialisées avec une précision maximale.
