Answer

Le Constrained Decoding garantit mathématiquement 100% de conformité au schéma JSON : le moteur d'inférence masque les jetons invalides avant l'échantillonnage Softmax.

  1. Les schémas JSON stricts imposent strict: true et additionalProperties: false sur chaque objet.
  2. Le moteur d'inférence (vLLM, Outlines ou OpenAI) compile le schéma en automate fini ou grammaire non contextuelle.
  3. À chaque position de décodage, les logits des tokens qui violeraient la syntaxe JSON sont fixés à $-\infty$.
  4. Le modèle ne peut matériellement générer aucun champ manquant, type erroné ou clé hallucinée.

L'automate syntaxique filtre les candidats lexicaux avant la sélection du token suivant.

  1. 1. Compilation Grammaticale ↗

    Le schéma JSON est traduit en automate d'états finis avant le début de l'inférence.

  2. 2. Calcul des Prédictions ↗

    Le réseau de neurones produit les scores bruts (logits) pour l'ensemble du vocabulaire.

  3. 3. Masquage Sélectif (Mask) ↗

    L'automate applique $-\infty$ à tous les tokens non autorisés à l'étape courante.

  4. 4. Émission Déterministe ↗

    La fonction Softmax ne retient que des jetons strictement conformes à la grammaire.
