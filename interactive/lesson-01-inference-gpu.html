Answer

Le modèle linguistique ne manipule aucun objet JSON applicatif : un gabarit de dialogue Jinja2 aplatit l'historique complet en chaîne textuelle brute avant le calcul GPU.

  1. Le serveur transforme le tableau de messages JSON en texte plat délimité par des balises <|im_start|>.
  2. La phase de Prefill traite l'intégralité du prompt en parallèle et initialise le KV Cache en mémoire VRAM.
  3. La phase de Décodage prédit chaque jeton séquentiellement en réutilisant le KV Cache pour éviter les recalculs.
  4. À l'entraînement, le masquage des pertes (Loss Masking) concentre l'apprentissage uniquement sur les réponses de l'assistant.

Le GPU optimise la mémoire vidéo en dissociant la lecture massive du prompt et la génération mot à mot.

  1. 1. Aplatissement Chat Template ↗

    Le serveur transforme le tableau JSON en une chaîne continue balisée par <|im_start|>.

  2. 2. Calcul du Prefill GPU ↗

    Les tenseurs de l'historique sont calculés en parallèle sur tous les cœurs CUDA.

  3. 3. Remplissage du KV Cache ↗

    Les clés et valeurs d'attention sont figées en mémoire vidéo haute vitesse pour les tours suivants.

  4. 4. Décodage Itératif ↗

    Chaque nouveau mot est échantillonné puis réinjecté jusqu'au token de terminaison <|im_end|>.
