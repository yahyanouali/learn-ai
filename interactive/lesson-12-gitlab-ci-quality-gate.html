Answer

L'agent s'exécute sans interface graphique dans les chaînes d'intégration continue : il évalue les commits et bloque les fusions non conformes via un Quality Gate automatisé.

  1. Le pipeline déclenche un conteneur éphémère à chaque événement de merge request.
  2. Une requête cURL interroge le modèle avec un schéma strict d'audit retournant une note de conformité.
  3. L'outil utilitaire jq extrait le score numérique et bloque le pipeline avec un code retour 1 si la note est inférieure à 80.
  4. L'outil OpenCode peut également tourner en mode headless natif via la commande opencode run "consigne".

Le conteneur CI audite automatiquement le code avant toute intervention humaine de relecture.

  1. 1. Déclenchement CI ↗

    Le développeur pousse sa branche et déclenche l'exécution du pipeline dans un conteneur Docker.

  2. 2. Calcul du Diff ↗

    Le script calcule la différence textuelle entre la branche courante et la branche principale.

  3. 3. Audit Déterministe ↗

    L'API OpenAI analyse les modifications avec strict: true et produit une note d'architecture.

  4. 4. Arbitrage jq ↗

    Le score est extrait et comparé au seuil d'acceptabilité pour autoriser ou bloquer la fusion.
