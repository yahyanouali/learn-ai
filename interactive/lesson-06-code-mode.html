Answer

Le Code Mode remplace des dizaines d'appels d'outils verbeux par l'émission d'un unique script TypeScript exécuté dans un bac à sable Bun sécurisé.

  1. L'approche ReAct classique multiplie les allers-retours HTTP et sature la fenêtre de contexte par accumulation de JSON intermédiaires.
  2. En Code Mode, le modèle écrit un script complet intégrant boucles, conditions et filtres en mémoire vive.
  3. Les milliers de lignes de données brutes sont filtrées directement dans la sandbox : seul le résultat synthétisé est renvoyé.
  4. La consommation globale de jetons est réduite de 85% sur les scénarios multi-étapes complexes.

Le traitement en mémoire vive isole les données intermédiaires volumineuses hors du contexte du modèle.

  1. 1. Génération du Programme ↗

    Le modèle produit un script TypeScript autonome utilisant des instructions JavaScript courantes.

  2. 2. Confinement Sandbox ↗

    Le runtime Bun lance le script dans un processus isolé aux privilèges et ressources strictement plafonnés.

  3. 3. Traitement en RAM ↗

    Les tableaux de logs volumineux sont analysés et agrégés sans jamais transiter sur le réseau du LLM.

  4. 4. Émission du Résultat ↗

    Seules les quelques lignes de conclusion sont imprimées sur la sortie standard puis réinjectées.
