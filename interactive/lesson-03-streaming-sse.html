L'Intention d'Action : finish_reason & Streaming SSE

Long image

A

Answer

L'émission d'une action par le modèle est signalée par finish_reason: "tool_calls". En streaming, les arguments JSON transitent sous forme de fragments textuels qu'il faut accumuler par index.

  1. Le discriminant finish_reason informe l'application du motif d'arrêt du modèle (tool_calls, stop, length).
  2. En mode streaming Server-Sent Events, chaque paquet data: transporte un delta contenant un index de fonction.
  3. Le client assemble les morceaux de chaîne brute dans un tampon dédié jusqu'à la réception du signal de fin.
  4. L'identifiant unique id (call_...) doit être préservé intact pour corréler la réponse physique de l'outil.

Comment le streaming SSE transmet-il un appel d'outil ?

Le serveur d'inférence envoie des micro-morceaux JSON que le client reconstitue en mémoire.

Diagram structure
  • Application Cliente client
  • Tampon d Accumulation buffer
  • Moteur d Inférence LLM server
  • client → server · POST stream: true
  • server → client · data: index 0, id call_123, name read_file
  • client → buffer · initialiser slot index 0
  • server → client · data: arguments {"path":
  • client → buffer · append arguments morceau 1
  • server → client · data: arguments "src/main.ts"}
  • client → buffer · append arguments morceau 2
  • server → client · data: finish_reason tool_calls
  • buffer → client · JSON complet parse et valide

Attention au parsing prématuré

Tenter d'exécuter JSON.parse() sur un fragment individuel déclenche immédiatement une erreur de syntaxe. Le runtime doit obligatoirement concaténer tous les deltas de l'index 0 jusqu'à la détection de finish_reason. En cas d'appels parallèles, chaque outil possède son propre index numérique indépendant dans le tableau.

Quels sont les codes d'arrêt du modèle et leur signification ?

La propriété finish_reason dicte le comportement de l'orchestrateur agentique à chaque tour.

Valeur de finish_reasonSignification TechniqueAction de l'Agent
"tool_calls"Le modèle sollicite l'exécution d'une ou plusieurs fonctions.Activer la boucleIntercepter, valider les permissions et exécuter l'outil
"stop"Le modèle a terminé sa réponse textuelle standard.Terminaison normaleAfficher le message à l'utilisateur et attendre sa saisie
"length"La fenêtre de contexte ou la limite max_tokens est atteinte.Payload incompletSignaler la troncature ou relancer une complétion partielle
"content_filter"La requête a enfreint une règle de sécurité du fournisseur.Blocage de sécuritéInterrompre la session et journaliser l'incident de modération
