3. Matrice d'Activation : Tool Calling Classique vs Code Mode (execute)

Critère Technique Situation A : "codeMode": false (Étapes 2 à 4) Situation B : "codeMode": true (Étape 6)
Déclaration dans tools[] Tous les schémas JSON de tous les outils MCP sont injectés dans tools[]. Un seul méta-outil dans tools[] : execute (signatures TS compactes dans system).
Orchestration Multi-Outils 15 appels d'outils = 15 allers-retours HTTP complets avec le serveur LLM. Le LLM écrit un script JS async exécuté en 1 seul aller-retour dans la sandbox locale.
Empreinte sur la Context Window Tous les JSON bruts intermédiaires s'accumulent dans messages[]. Les payloads intermédiaires restent en RAM locale ; seul le return final entre dans role: "tool".
